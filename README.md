# A.T.R.A.K Store

فروشگاه فارسی/انگلیسی پوشاک تاکتیکال با پنل مدیریت.

## اجرا
Node.js نسخه 18 یا جدیدتر نصب کنید.
در پوشه پروژه:
```bash
npm start
```
سپس:
- فروشگاه: http://localhost:3000
- پنل مدیریت: http://localhost:3000/admin.html

## امنیت
رمز پیش‌فرض فقط برای دموی محلی است: `ChangeMe123!`
برای سرور واقعی، متغیر محیطی `ADMIN_PASSWORD` را با یک رمز قوی تنظیم کنید.

## امکانات
- مدیریت محصولات، قیمت و موجودی
- مشاهده و تغییر وضعیت سفارش‌ها
- تنظیم نام و توضیحات فارسی/انگلیسی
- SEO پایه، canonical، Open Graph، JSON-LD، robots.txt و sitemap.xml
- جست‌وجو با نام فارسی/انگلیسی و «Atrak / A.T.R.A.K / اترک / آترک»

## پرداخت
ثبت سفارش در این نسخه فعال است، اما اتصال درگاه واقعی نیاز به انتخاب درگاه و اطلاعات پذیرندگی دارد.
